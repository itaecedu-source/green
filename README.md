# 🛒 GreenCart Ordering System

A modern and responsive online grocery ordering system built with:

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Product catalog
- Product categories
- Search
- Shopping cart
- Add/remove products
- Quantity controls
- Automatic subtotal
- Delivery calculation
- Free delivery over $50
- Checkout form
- Order confirmation
- Automatic order number
- Local order storage
- Responsive mobile design

## Project Structure

GreenCart/
│
├── index.html

## How to Run

Open `index.html` in a browser.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - index.html
   - style.css
   - script.js
   - README.md
3. Go to Settings.
4. Select Pages.
5. Under "Build and deployment", select:
   - Deploy from a branch
6. Select the `main` branch.
7. Select `/root`.
8. Click Save.

Your GreenCart website will then be available through GitHub Pages.

## Important

This version is a frontend ordering system.

Orders are stored in the browser's LocalStorage.

For a real business system, connect the checkout to a backend/database such as:

- Firebase
- Supabase
- Google Sheets + Apps Script
- Node.js + database

This would allow the store owner to receive and manage orders from different customers and devices.
